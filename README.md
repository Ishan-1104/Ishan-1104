## 🏆 Featured Projects

### 🔬 [ResearchMind — Multi-Agent AI Research System](https://github.com/Ishan-1104/Multi_Agent_System)
A multi-agent research pipeline that takes any topic and automatically **searches the web, scrapes full content, drafts a structured report, and critiques its own output** — orchestrated end-to-end with LangChain.
- **Pipeline:** Search Agent (Tavily + Mistral tool-calling) → Scraper (BeautifulSoup, with fallback across candidate URLs) → Writer Chain (900–1200 word structured report) → Critic Chain (self-scored feedback)
- Live pipeline UI in Streamlit with real-time stage tracking, run history, and Markdown export
- **Stack:** Python, LangChain, Mistral AI, Tavily, BeautifulSoup4, Streamlit
- 🔗 **Live demo:** [research-mind-18.streamlit.app](https://research-mind-18.streamlit.app/)

### 🎬 [AI Video Assistant (Video-Agent)](https://github.com/Ishan-1104/Video-Agent)
Turns any meeting recording or YouTube video into a **searchable, chattable knowledge base** using Retrieval-Augmented Generation.
- Transcribes audio/video (English + Hinglish), auto-generates a title & summary, and extracts action items, key decisions, and open questions
- **Chat with your video/meeting** via a RAG pipeline: Chroma vector store + HuggingFace embeddings + LangChain LCEL + Mistral AI
- Both a scriptable CLI and a full Streamlit web UI with live pipeline status, dashboards, and export
- **Stack:** Python, LangChain, Mistral AI, ChromaDB, Sentence-Transformers, Streamlit
- 🔗 **Live demo:** [video-agent-18.streamlit.app](https://video-agent-18.streamlit.app/)

### 💬 [Streamify](https://github.com/Ishan-1104/Streamify)
A full-stack, real-time **chat & video communication platform** built on a clean `frontend` / `backend` architecture and deployed live.
- **Real-time messaging** — instant one-on-one (and group) text chat with a responsive, modern UI
- **Video calling** — in-app video call functionality alongside chat, so conversations aren't limited to text
- **Authentication & user accounts** — signup/login flow with protected routes, so chat and calls are tied to a real user identity
- **Friends / connections system** — users can find, add, and manage contacts before chatting or calling them
- **Stack:** JavaScript across the full stack (Node.js/Express-style backend + a React-based frontend), deployed on Vercel
- 🔗 **Live demo:** [streamify-eight-tau.vercel.app](https://streamify-eight-tau.vercel.app)

> *Note: exact backend framework/real-time libraries (e.g. Express, Socket.io/WebRTC provider) — worth naming explicitly in the repo's own README so visitors don't have to open `backend/` to find out.*

### 📄 [ResumeForge AI](https://github.com/Ishan-1104/resumeforge-ai-1)
AI-powered SaaS-style tool that turns raw project descriptions into **ATS-ready resume content** — bullet points, summaries, and skills lists — powered by Groq's `llama-3.3-70b-versatile`.
- 🔗 **Live demo:** [resumeforge-ai-five.vercel.app](https://resumeforge-ai-five.vercel.app)
- **Stack:** Next.js 15, TypeScript, Tailwind CSS, Groq API

### 🎥 [CineAI](https://github.com/Ishan-1104/CineAI)
An AI-powered movie recommendation platform built on a client/server architecture.
- **Stack:** JavaScript (MERN-style client/server split)

### 🩺 [Multi-Disease Prediction System](https://github.com/Ishan-1104/multi-diseases)
A machine learning app that predicts the likelihood of **diabetes, heart disease, and Parkinson's disease** from patient data.
- Trained scikit-learn models serialized and served via a Python prediction script
- **Stack:** Python, scikit-learn, Pandas
