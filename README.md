### 🔬 [ResearchMind — Multi-Agent AI Research System](https://github.com/Ishan-1104/Multi_Agent_System)
A multi-agent research pipeline that takes any topic and automatically **searches the web, scrapes full content, drafts a structured report, and critiques its own output** — orchestrated end-to-end with LangChain.

- **Pipeline:** Search Agent (Tavily + Mistral tool-calling) → Scraper (BeautifulSoup, with URL fallback) → Writer Chain (900–1200 word report) → Critic Chain (self-scored feedback)
- Live Streamlit UI with real-time stage tracking, run history, and Markdown export

**Stack:** `Python` `LangChain` `Mistral AI` `Tavily` `BeautifulSoup4` `Streamlit`

🔗 [Live demo](https://research-mind-18.streamlit.app/)

- CLI + full Streamlit web UI with live pipeline status and export

**Stack:** `Python` `LangChain` `Mistral AI` `ChromaDB` `Sentence-Transformers` `Streamlit`

🔗 [Live demo](https://video-agent-18.streamlit.app/)
